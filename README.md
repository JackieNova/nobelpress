# nobelpress

A personal academic website about mathematics, electronic information, artificial intelligence and the history of science.

## Publish with GitHub Pages

In Settings > Pages, select Deploy from a branch, main, and / (root).
The website entry point is index.html. The .nojekyll file keeps the static files unchanged.

## Update

Update app.js, style.css, index.html or files under assets, then commit to main.
